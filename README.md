# JAV_limdal_lundgren
Version: 1.0.1

Welcome to Farming Game, a game about farming!

Your objective is to earn money by purchasing and planting crops, waiting untill they are ripe, and then harvesting before they spoil. Have fun!

To run:
 1. Compile with: javac -d out (Get-ChildItem -Path src -Recurse -Filter *.java).FullName
 2. Run with    : java -cp out Main
